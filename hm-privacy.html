一、前言

「家有好物」（以下简称“本应用”）是一款由白焕志（以下简称“我们”）开发的纯离线应用。我们深知个人信息对您的重要性，并会尽全力保护您的个人信息安全可靠。我们严格遵守《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》等相关法律法规，按照业界成熟的安全与隐私标准，采取严格的安全保障措施，保护您的个人信息。

特别说明：本应用的物品管理与数据备份功能完全离线运行、不设服务器，您记录的物品等数据不会上传；本应用自身不收集、不存储您的这些数据。

本应用仅通过集成的 uni-ad 广告 SDK 展示广告，该 SDK 会在您使用过程中由第三方广告平台采集必要的设备信息用于广告投放。本政策将帮助您了解以下内容：

  • 我们如何收集和使用您的个人信息
  • 设备权限申请与使用目的
  • 我们如何存储个人信息
  • 我们如何共享、转让、公开披露您的个人信息
  • 我们如何保护您的个人信息
  • 您的权利
  • 我们如何处理儿童的个人信息
  • 本政策如何更新
  • 如何联系我们

二、我们如何收集和使用您的个人信息

2.1 本应用自身不收集任何个人信息

「家有好物」不注册账号、不要求登录，本应用自身不采集您的个人信息。您在本应用中的物品、图片等数据均仅存储在您的设备本地，不会上传至任何服务器。

2.2 第三方 SDK 采集的信息

为实现广告展示功能，本应用集成了以下第三方 SDK，这些 SDK 会依据其自身隐私政策采集相关信息：

（1）DCloud App 引擎（uni-app 框架）

我们的产品基于 DCloud uni-app（5+ App/Wap2App）开发，应用运行期间需要收集您的设备唯一识别码（IMEI/android ID/DEVICE_ID/IDFA、SIM 卡 IMSI 信息、OAID）以提供统计分析服务，并通过应用启动数据及异常错误日志分析改进性能和用户体验，为用户提供更好的服务。详情内容请访问 《DCloud App引擎隐私政策》。

（2）uni-AD 原生广告 SDK

  • 第三方主体：数字天堂（北京）网络技术有限公司
  • 使用场景：向最终用户投放广告时使用
  • 使用目的：广告投放、三方广告联盟SDK聚合服务
  • 收集的信息范围：
    • 必要信息：设备信息（设备品牌、型号、操作系统版本、分辨率、设备语言、手机系统时间、设备名称、时区、屏幕密度），应用信息（应用名、应用包名、版本号），设备信息（网络类型、IP地址、User Agent信息、BSSID、SSID），设备标识符（如IMEI/MEID、IMSI、GAID（仅GMS服务）、AndroidID、OAID），运营商信息，位置信息，传感器，应用安装列表
  • 收集方式：SDK自行采集，不涉及数据共享
  • 隐私政策链接：https://dcloud.io/license/uni-ad.html

2.3 征得授权同意的例外

根据法律法规及相关国家标准，以下情形中，我们收集和使用您的信息无需征得您的授权同意：

  • 与国家安全、国防安全直接相关的；
  • 与公共安全、公共卫生、重大公共利益直接相关的；
  • 与犯罪侦查、起诉、审判和判决执行等直接相关的；
  • 出于维护您或其他个人的生命、财产等重大合法权益但又很难得到本人同意的；
  • 所收集的您的个人信息是您自行向社会公众公开的；
  • 从合法公开披露的信息中收集的您的个人信息；
  • 根据您的要求签订或履行合同所必需的；
  • 用于维护软件及相关服务的安全稳定运行所必需的；
  • 法律法规规定的其他情形。

2.4 设备权限申请与使用目的

本应用仅在您主动使用对应功能时申请必要权限，并在申请前同步弹窗告知该权限的使用目的；不会在启动时批量申请权限，也不会申请与功能无关的权限。所有权限均可在您的设备系统设置中随时关闭，关闭后仅影响对应功能，不影响其他功能的使用，也不会删除您已保存的数据。

三、我们如何存储个人信息

本应用自身不收集和存储您的个人信息。第三方 SDK 收集的信息存储地点请参照各 SDK 的隐私政策。本应用自身不存储您的任何个人信息。第三方 SDK 的信息存储期限详见各 SDK 隐私政策。

本应用自身不设服务器，您记录的物品、图片等数据存储在您的设备本机，保存期限至您主动删除数据或卸载本应用为止。第三方 SDK 采集的信息存储于中华人民共和国境内，本应用不涉及向境外提供个人信息。

四、我们如何共享、转让、公开披露您的个人信息

4.1 共享

本应用自身不收集、不共享您的个人信息。广告 SDK 采集的信息由各 SDK 自行处理，不涉及数据共享。我们仅在以下情况可能涉及信息共享：在获取明确同意的情况下共享；根据法律法规规定，或按政府主管部门的强制性要求，对外共享您的个人信息。

4.2 转让

我们不会将您的个人信息转让给任何公司、组织和个人，但以下情况除外：在获取明确同意的情况下转让；在涉及合并、收购或破产清算时，如涉及到个人信息转让，我们会要求新的持有您个人信息的公司、组织继续受此隐私政策的约束。

4.3 公开披露

我们仅会在以下情况下，公开披露您的个人信息：获得您明确同意后；基于法律的披露（在法律、法律程序、诉讼或政府主管部门强制性要求的情况下）。

五、我们如何保护您的个人信息

本应用为纯离线应用，数据不离开您的设备，因此不存在数据传输和服务器存储的安全风险。对于第三方广告 SDK 采集的信息，我们要求其按照业界标准的安全保护措施进行处理，防止信息遭到未经授权的访问、公开披露、使用、修改、损坏或丢失。

六、您的权利

您对自己记录的数据享有充分控制权，可就个人信息处理行使以下权利：

  • 查阅、更正与删除：您可在应用内随时查看、修改、删除自己记录的物品、房间、标签与图片，也可通过“我的—清空所有数据”一次性删除全部本机数据；
  • 撤回同意：您可在“我的—关于”中撤回对个人信息处理的同意并重新选择（撤回后本应用将重新征求您的同意）；如需停止广告 SDK 的信息采集，您也可以关闭本应用的网络连接或卸载本应用；
  • 设备广告标识符重置：您可以在设备系统设置中重置或关闭广告标识符（如 Android 设备的“广告 ID”）；
  • 账号注销：本应用不提供账号注册、登录功能，因此不涉及账号注销事项；
  • 第三方 SDK 相关权利：如您需要行使与第三方 SDK 采集信息相关的权利，可根据本政策 2.2 节所列联系方式联系相应 SDK 主体。

七、我们如何处理儿童的个人信息

本应用主要面向成人。如果没有父母或监护人的同意，儿童不应使用本应用。对于经父母同意而使用本应用的情况，我们只会在法律法规允许、父母或监护人明确同意或者保护儿童所必要的情况下使用或公开披露此信息。尽管当地法律和习俗对儿童的定义不同，但我们将不满 14 周岁的任何人均视为儿童。

八、本政策如何更新

我们可能适时修订本隐私政策的条款。未经您明确同意，我们不会削减您按照本隐私政策所应享有的权利。我们会在本页面上发布对本政策所做的任何变更。对于重大变更，我们会以显著方式通知您。本政策所指的重大变更包括但不限于：我们的服务模式发生重大变化；个人信息共享、转让或公开披露的主要对象发生变化；您参与个人信息处理方面的权利及其行使方式发生重大变化。
